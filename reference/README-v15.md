# One Grain — reference v15 (lit)

`v15-lit.html` is the spec for Phase 4b: v10 plus the art direction pass (per-world
light tuning, palette, type, HUD legibility, pacing, hero grain), the new clock on Display
(a live millisecond counter, "on your screen"), and the new final:

display → now ("become"): push in to macro, the sub-pixels' light goes out, the grid
loosens, each sub-pixel cluster spreads into the area it lit and turns into sand, then the
camera pulls back. The hero grain hovers, loses its light, lands among the other grains and
can no longer be told apart.

Worlds 0–13 are generated exactly as in v8/v10; only the final world is new.
